# 🌿 NAFAS — Boutique de produits naturels

> **NAFAS** est une boutique en ligne dédiée aux produits naturels : bougies aromatisées, suspensions parfumées et baumes d'aromathérapie. 🕯️🌱

🔗 **Visiter la boutique :** [https://smo2z5gkks7d2sgrwcs5s7.streamlit.app/](https://smo2z5gkks7d2sgrwcs5s7.streamlit.app/)

---

## ✨ Fonctionnalités

- 🛍️ **Catalogue produits** avec photos, prix et descriptions
- 🛒 **Panier** et passage de commande en ligne
- 🚚 **Livraison par wilaya** (58 wilayas d'Algérie) + livraison gratuite paramétrable
- 👨‍💼 **Espace vendeur privé** pour gérer produits, commandes et identité de la boutique
- 🗂️ **Stockage permanent** des données via Google Sheets
- 📱 **Interface responsive** (ordinateur et mobile)

---

## 🛠️ Technologies utilisées

- **[Streamlit](https://streamlit.io/)** — interface web
- **Python** — logique de l'application
- **Google Sheets API** — base de données (produits, commandes, livraison)
- **Streamlit Community Cloud** — hébergement
